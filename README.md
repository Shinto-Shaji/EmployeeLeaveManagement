# Employee Leave Management System

## Overview

A web-based Employee Leave Management System built using ASP.NET Core MVC that allows employees to apply for leave and administrators to manage leave requests.

## Features

- Employee Registration
- Employee Login & Logout
- Session-based Authentication
- Apply for Leave
- View Leave History
- Admin Login
- Approve / Reject Leave Requests
- Leave Balance Tracking

## Tech Stack

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- Bootstrap 5
